# MATH SCHOOL 3D V5 — Escola Interativa

Versão V5 do protótipo educacional 3D.

## Novidades
- corredor escolar com teto, luminárias, piso, bancos e bebedouro;
- diretor humanoide caminhando e oferecendo desafio;
- alunos/NPCs circulando;
- Sala 1 PA e Sala 2 PG com entrada funcional;
- interiores próprios com carteiras, quadro, fórmulas e professor;
- botão para voltar ao corredor;
- desafios de PA/PG, XP e controles mobile;
- biblioteca e laboratório mantidos como pontos de desafio.

## Executar
```bash
npm install
npm start
```

Railway: pode usar o mesmo projeto/repositório e domínio. Após substituir os arquivos e fazer commit, o deploy atualiza.
